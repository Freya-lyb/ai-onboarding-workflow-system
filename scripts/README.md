# Workflow Validation Demo Scripts

This folder contains sanitized demonstration scripts inspired by onboarding workflow coordination systems used in enterprise onboarding environments.

The scripts are designed for portfolio and educational purposes only and do not contain production infrastructure, internal business logic, or proprietary company implementations.

---

# Purpose

The scripts demonstrate several onboarding workflow concepts, including:

- workflow sequencing
- task dependency validation
- onboarding progression logic
- blocked task detection
- synthetic onboarding data generation
- role-based onboarding ownership
- onboarding workflow simulation

The examples are intentionally simplified and use fully synthetic onboarding data.

---

# Files

| File | Purpose |
|---|---|
| `synthetic_onboarding_data.py` | Generates synthetic onboarding workflows, tasks, employees, and dependencies |
| `workflow_validation_demo.py` | Simulates onboarding workflow validation and dependency checking |

---

# Example Workflow Concepts

The demo workflows simulate onboarding processes such as:

- employee onboarding
- IT provisioning
- account setup
- document verification
- product team onboarding
- onboarding milestone tracking

The examples include onboarding concepts such as:

- sequential onboarding tasks
- onboarding blockers
- overdue onboarding steps
- role ownership
- escalation scenarios
- workflow progression

---

# Notes

These scripts are intentionally lightweight and simplified.

They are not intended to represent full production onboarding systems, infrastructure, or enterprise security implementations.

All onboarding workflows, employee data, company names, and onboarding scenarios are synthetic and sanitized.
